Problems with the Linear Probability Model

  • Makes impossible predictions (values not between 0, 1)

  • Non-normality of residuals

    • \(\hat{p}\) or (1-\(\hat{p}\))

  • Heteroskedasticity

    • Variance is influenced by \(\hat{p}\)

Generalized linear model

Generalized linear model

Regression models with non-normal response likelihoods

\[\begin{align*} Y_i & \sim \mathrm{Dist}(\mu_i, \tau) \\ g(\mu_i) & = \eta_i \\ \eta_i & = \beta_0 + \beta_1 X_{1i} + \beta_2 X_{2i} + \ldots \end{align*}\]Where:

  • \(y\) is referenced with \(\mu\)

  • \(g\) is link function (in logistic regression we use logit link)

What distribution do we use to model this process?

  • We assume that there is some probability p of responding correctly (or selecting what is coded as 1)

  • We don’t know this probability, so we want to use the data to estimate it

Bernoulli distribution

Distribution of a single, discrete binary outcome \[y\sim Bernoulli(p)\]

  • A Bernoulli distribution generates a 1 (“success”) with probability p

  • And a 0 (“failure”) with probability 1−p=q

    • \(\mu\) = E(X)=p
    • \(\sigma^2(X)=p(1-p)\)



Binomial distribution

Distribution of discrete counts of independent outcomes over a certain set of trials

\[y\sim binomial(N,p)\]

  • N = number of trials

  • p = probability of “y = 1”

    • \(\mu\) = E(X)=np$
    • \(\sigma^2(X)=np(1-p)\)
    • \(\sigma(X)\)=\(\sqrt{np(1-p)}\)

Logit link

  • The logit link transforms a linear model in the log-odds metric:

\[\begin{equation*} \log\left(\frac{p}{1 - p}\right)=b_0+b_1X \end{equation*}\]

  • To a non-linear model in the probability metric:

\[\begin{equation*} p(logit)=\frac{e^{logit}}{1+e^{logit}} \end{equation*}=\frac{exp(logit)}{1+exp(logit)}\]

Logit link

  • Step 1

    • Transform probability into odds

      • The “odds” of an event are just the probability it happens divided by the probability it does not happen

\[\textrm{Odds} = \frac{\# \textrm{successes}}{\# \textrm{failures}}= \frac{\# \textrm{successes}/n}{\# \textrm{failures}/n}= \frac{p}{1-p}\]

Logit Link

  • Step 2

    • When we convert a probability to odds, odds always > 0

      • Asymmetric

      • Curvy

        • Problematic for linear model

    • Solution: take log of the odds

    \[logit = log(\frac{p}{1-p})\]

If you look at the figure here, we have the odds scale..
P as a function of odds –> bounded to 0. P<0.5 is crammed to this region, and the rest extends to infinity

Odds are always positive and asymmetric — an odds of 2 means twice as likely but an odds of 0.5 means half as likely.

Now we can take the log

  • Suddenly — symmetric. Zero sits in the middle. p < 0.5 goes negative. p > 0.5 goes positive. Equal room on both sides.

  • This is a scale where regression works!

Probabilities, Odds, and Log Odds

Two Link Functions You Need to Know [B1]

Logit link (today)

  • Maps probability \((0, 1)\) → log-odds \((-\infty, +\infty)\)

\[\text{logit}(p) = \log\frac{p}{1-p}\]

  • Used for: Binomial / Logistic models

  • Inverse (logistic function) produces the S-curve

  • Effect on outcome: compressed near 0 and 1

Log link (coming soon)

  • Maps positive values \((0, +\infty)\) → real line \((-\infty, +\infty)\)

\[\log(\mu) = \beta_0 + \beta_1 X\]

  • Used for: Poisson / Count models

  • Inverse is exponentiation: \(\mu = e^{\beta_0 + \beta_1 X}\)

  • Effect on outcome: exponential scaling

Note

Both links solve the same problem — mapping a constrained parameter onto an unconstrained linear model. The logit handles probabilities; the log handles positive counts.

Best fitting squiggle

  • In standard linear regression we use least squares to find the best fitting line

  • But with binary data, we need a different approach…

  • Step 1: We need find where points lie on line and get corresponding logits

ML: Logistic Regression

  • Step 2: Project them onto the probability scale (rotate the log-odds line)

Now what?

  • Step 3: We keep rotating the log odds (line) and projecting data on to it and transforming into probabilities

    • Until we find the set of parameters that maximizes the likelihood of observing our data!

MLE vs. OLS

  • OLS minimizes sum of squared residuals
  • MLE finds parameter values that make observed data most probable
  • No closed-form solution — uses iterative algorithms (Newton-Raphson / IRLS)

Can we transform the data?

We need a scale where the relationship is linear. Can we just… transform?

Individual 0/1?

  • logit(0) = \(-\infty\)
  • logit(1) = \(+\infty\)
  • Dead end.

Aggregated proportions?

  • logit(0.15) = −1.73
  • logit(0.85) = +1.73
  • Works fine.

So we have two options.

But this needs groups to compute proportions from. Our coins had that — 20 tosses at each weight. What if we wanted predictors like spin rate, etc. that can vary across tosses ?

Option 1 requires aggregation which requires clear grouping / binning (which can be lossy).

Option 2: Let the model handle it

glm() doesn’t transform your data. It works from the other direction.

  1. Propose a line in log-odds: \(\;\text{logit}(\hat{p}) = \beta_0 + \beta_1 x\)
  1. Convert to predicted probabilities: \(\;\hat{p} = \text{plogis}(\beta_0 + \beta_1 x)\)
  1. Score against your raw data (0/1s or counts) — “how likely is what I observed?”

The model builds its line in log-odds space. Then it comes to your data to check its work.

Option 2: The model’s predictions gets a new scale

The model’s predicted probability \(\hat{p}\) can be expressed \(\hat{p}\) on three scales:

Probability

  • Bounded: \([0, 1]\)
  • S-shaped
  • What you want to estimate and interpret
  • Can’t use OLS

Odds

  • Bounded: \([0, +\infty)\)
  • \(\frac{\hat{p}}{1-\hat{p}}\)
  • Still undesirable for OLS

Log-odds

  • Unbounded: \((-\infty, +\infty)\)
  • \(\log\frac{\hat{p}}{1-\hat{p}}\)
  • Model is happy because now there’s a Linear relationship
  • And you’re happy because you can map it to an interpetable parameter

What is Maximum Likelihood?

In OLS — we minimize the squared residuals. Closed-form solution.

With binary data — squared residuals don’t make sense. Instead:

Maximum Likelihood Estimation (MLE)

Find the parameter values that make the observed data least surprising/ most likely.

The logic:

  1. Propose some parameter values (\(\beta_0\), \(\beta_1\))

  2. Ask: if these were the true values, how probable is the data I actually got?

  3. Score that probability — the likelihood

  4. Repeat with different values until the likelihood is as high as possible

The parameters at the peak = the maximum likelihood estimates.

MLE for logistic regression

How does MLE apply to our problem?

The model proposes a straight line in log-odds: \(\;\text{logit}(p) = \beta_0 + \beta_1 \cdot \text{lead_weight}\)

Converts to probabilities: \(\;\hat{p}_i = \text{plogis}(\beta_0 + \beta_1 x_i)\) for each observation

Scores against the data:

  • Observation got a 1 ●? Score = \(\hat{p}_i\) — higher is better

  • Observation got a 0 ●? Score = \(1 - \hat{p}_i\) — higher is better

Total likelihood = multiply all the scores: \(\;\;L = \prod_{i=1}^{n} \hat{p}_i^{y_i}(1-\hat{p}_i)^{1-y_i}\)

Try thousands of lines → find the one with the highest \(L\).

That line’s \(\beta_0\) and \(\beta_1\) are your estimates.

Three candidate lines — which one fits our coin data best?

Where does the score come from?

Model predicts \(\hat{p} = 0.88\) for the 6g coin. It lands heads. How likely was that?

*Bernoulli Likelihood formula:**

\[L(\hat{p}_i) = \hat{p}_i^{\,y_i} \cdot (1 - \hat{p}_i)^{1-y_i}\]

\(y = 1\): just \(\hat{p}\). \(\;\;\) \(y = 0\): just \(1 - \hat{p}\).

Two observations? Multiply. 160 observations? Multiply all scores → likelihood.

But 160 tiny numbers multiplied → computer underflow. So we take the log:

\[\log {L} = \sum_{i=1}^{n} \left[ y_i \log(\hat{p}_i) + (1 - y_i) \log(1 - \hat{p}_i) \right]\]

Same ranking and same peak (what we need for max). And numerically stable.

Build the likelihood from a single observation. Left panel: if the coin lands heads (Y=1), the likelihood IS the predicted probability. The grey line is L(p̂) = p̂ — a straight line. At p̂ = 0.88, the green dot reads off 0.88. High prediction for an event that happened → high score. Right panel: same prediction, but tails (Y=0). Now L(p̂) = 1 − p̂. At p̂ = 0.88, the red dot reads off 0.12. The model predicted 88% heads but got tails — low score, the model was surprised.

The formula combines both. When y=1, the exponents collapse to p̂. When y=0, they collapse to 1−p̂.

For multiple observations, multiply. But 160 numbers between 0 and 1 multiplied together → astronomically small. Like 10⁻⁴⁷. Computers can’t handle that — underflow. So we take the log. Log turns products into sums. Same ranking — if likelihood A beats likelihood B, log-likelihood A also beats log-likelihood B. Same peak. Just stable arithmetic. (J: Let me show you exactly where the score comes from. Left panel — the coin lands heads. The likelihood function for a single heads is just a straight line: the higher your predicted probability, the higher your score. Our model predicted 0.88, so the score is 0.88. Green dot, right there. Right panel — same prediction, but tails happened. Now the likelihood goes the other way — high prediction for something that didn’t happen means a LOW score. 0.12. Scoring each guess

For each observation:

  • If \(Y_i = 1\) (heads ●): score = \(\hat{p}_i\) — higher is better

  • If \(Y_i = 0\) (tails ●): score = \(1 - \hat{p}_i\) — higher is better

Log-likelihood = sum of log(scores) across all observations

compute_ll <- function(b0, b1, data) {
  p_hat <- plogis(b0 + b1 * data$lead_weight)
  sum(data$outcomes * log(p_hat) + (1 - data$outcomes) * log(1 - p_hat))
}

Case Study: Losing Weight

  • These data are a sample of 500 teens from data collected in 2009 through the U.S. Youth Risk Behavior Surveillance System (YRBSS)

  • Are the odds that young females report trying to lose weight greater than the odds that males do? Is increasing BMI associated with an interest in losing weight, regardless of sex?

Trying to lose weight

  • Selected variables:

DV: *lose.wt.01, which is coded 1 when someone indicated they were trying to lost weight and 0 when they were not trying to. This is a dichotomized version of the lose.wt factor variable.

  • Our two predictor variables will be:

    • sex and its related dummy variable female
    • bmipct, which is the percentile for a given BMI for members of the same sex

Hypothesis test for \(\beta_j\)

  • Hypotheses:

    • \(H_0\): \(\beta_j\) = 0

    • \(H_a\): \(\beta_j \neq 0\)

  • Test Statistic: \[\text{Wald z} = \frac{\hat{\beta}_j - 0}{SE_{\hat{\beta}_j}}\]

  • CIs: \[\Large{\hat{\beta}_j \pm z^* SE_{\hat{\beta}_j}}\]

Interpreting slope: \(b_1\)

  • If X is a categorical predictor

    • Then \(b_1\) is the difference in the log-odds between group X and the baseline
  • Going from men to women, there is a change in the the log odds of wanting to lose weight of 1.09

Coefficient effect size: Odd’s Ratio

  • We can take the exp() of the log odds and get OR

    • The odds of Y for group X (females) are expected to be exp(\(b_1\)) times the odds of Y for the baseline group

      • Greater than 1: One unit increase, the event is more likely to occur

      • Less than 1: One unit increase, the event is less likely to occur

      • Equals 1: One unit increase, the likelihood of the event does not change

    • We can describe the OR in terms of percentage increase/decrease

(OR-1) * 100  # get probability of increase/decrease

Coefficient Effect Size: Odd’s Ratio

  • The odds of wanting to lose weight in females is 2.98 times the odds of wanting to lose weight in men

    • The odds of females wanting to lose weight are 198% higher than the odds of males wanting to lose weight

Marginal effects

  • We can also calculate differences in probabilities

    • Difference in probabilities is called risk difference

  • Marginal effects

    • Change in probability that the outcome occurs for a 1 unit change in the predictor

      • Average marginal effect (AME)

  • For categorical variables it is just the probability difference between groups

    • Much easier to interpret than odds ratios!

Logistic Multiple Predictors

  • The first will have both female and bmipct as predictors:

\[ \begin{align*} \text{lose.wt.01}_i & \sim \operatorname{Binomial}(n = 1, p_i) \\ \text{logit}(p_i) & = \beta_0 + \beta_1 \text{female}_i + \beta_2 \text{bmipct}_i. \end{align*} \]

  • The second model will add an interaction term between the two predictors:

\[ \begin{align*} \text{lose.wt.01}_i & \sim \operatorname{Binomial}(n = 1, p_i) \\ \text{logit}(p_i) & = \beta_0 + \beta_1 \text{female}_i + \beta_2 \text{bmipct}_i + \beta_3 \text{female}_i \cdot \text{bmipct}_i. \end{align*} \]

Model fit

Binned residuals

  • Binned residuals

    • Calculate raw residuals
    • Order observations (probabilities of DV or predictor variable)
      • Create g bins of approximate equal size \(\sqrt(n)\)
    • Calculate average residuals
    • Plot average residuals vs. average predicted probability (or predictor value)

  • Grey bands represent ±2 SE — ideally ~95% of points fall within

#performance::binned_residuals()
binnedplot(fitted(fit4), residuals(fit4, type="response"))

Binned residuals

  • Look for patterns

    • Nonlinear trend may be indication that squared term or log transformation is required

  • If bins have average residuals with large magnitude

    • Look at averages of other predictors across bins

    • Interaction may be required

  • Rule of thumb: If >5% of bins fall outside the bands, model may need improvement

Assumptions

Logistic regression assumptions

  • Outcome is dichotomous

  • Observations are independent

  • Linearity (in the log odds)

  • No normality assumptions

  • Homogeneity of variance

    • Variance varies with \(p\)

Reporting

Tip

We fitted a logistic model with a logit link (estimated using ML) with sex and bmipct predicting desire to lose weight (formula: lose.wt.01 ~ 1 + female+ bmipct). The model’s explanatory power is substantial (Tjur’s \(R^2\) =0.30). The probability of females wanting to lose weight was 33% higher, b= 1.86, 95% CI [1.37, 2.38], p < .001; OR = 2.98, 95% CI [3.93, 10.9]. An increase in BMI was associated with an increased probability of wanting to lose weight, b = 0.05, 95% CI [0.04, 0.06], p < .001, OR = 1.05, 95% CI [1.04, 1.06]. Looking at the average marginal effect, 1 unit increases in BMI was associated with a 80% increase in desire to lose weight.

Reporting Checklist

  • Report the link function and estimation method (e.g., logit link, ML estimation)
  • Report log-odds coefficients and odds ratios with 95% CIs
  • Report a measure of model fit (McFadden \(R^2\), Tjur \(R^2\), etc.)
  • Consider reporting marginal effects for practical significance
  • Include sample size, number of events, and events-per-variable ratio
  • Mention any convergence issues or model diagnostics

Common Mistakes

  • Interpreting log-odds coefficients as if they were probabilities

  • Forgetting that effects are non-linear on the probability scale

    • A 1-unit change in X does not have a constant effect on P(Y=1)

  • Using \(R^2\) from linear regression — use pseudo \(R^2\) measures instead

  • Not checking for multicollinearity (VIF still applies!)
